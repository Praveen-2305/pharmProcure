## PROJECT REPORT SUMMARY

This report documents the design, implementation, and evaluation of AutonoSource — a
multi-agent procurement risk and vendor intelligence platform developed as a proof-of-concept
on the `kamalesh` branch. The platform demonstrates hybrid Retrieval-Augmented Generation
(RAG) with a dual vector/graph retriever, LangGraph agent orchestration, deterministic pricing
checks in Indian Rupees (INR), and an explainable, revision-loop critique mechanism for
procurement decisioning.
